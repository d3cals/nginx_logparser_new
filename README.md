# Nginx Log Analyzer


## Описание проекта:
Nginx Log Analyzer - инструмент для парсинга и анализа логов web-сервера Nginx

## Стратегия ветвления:
За базу взята страгетия упрощенного GitFlow:
- `main`: Основная и стабильная ветка. Содержит готовый к развертыванию код, любые исправления и/или добавления добавляются только через merge request
- `release/X`: Ветки для подготовки релизов. Предназначена для финальных тестов, исправления последних багов перед выпуском в продакшн. Изменения вносятся через `bugfix` и `hotfix`
	- Пример:
		- `release/1` - для версии 1
		- `release/1.05` - для версии 1.05
- `feature/название_фичи`: Ветки для разработки новых фич. Создаются от `main`, сливаются туда же через merge request
	- Пример:
		- `feature/add_login_through_email` - Добавление возможности входа через email
		- `feature/add_ads` - Добавление рекламы
- `bugfix/название_бага`: Ветки для исправления багов. Создаются от `main` и `release/*`
